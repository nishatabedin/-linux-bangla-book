# 🐧 সহজ বাংলায় লিনাক্স — শূন্য থেকে এক্সপার্ট (A to Z)

> একদম নতুন (fresher) মানুষের জন্য লেখা একটি পূর্ণাঙ্গ লিনাক্স বই।
> শুধু "কোন কমান্ড" না — **কেন**, **কীভাবে**, আর **ভেতরে কী ঘটে** — সবকিছু সহজ বাংলায়।

---

## এই বই কার জন্য?

- যে আগে কখনো লিনাক্স ব্যবহার করেনি
- যে Windows থেকে লিনাক্সে আসতে চায়
- যে SysAdmin, DevOps, Cloud, Cyber Security বা Backend Developer হতে চায়
- যে কমান্ড মুখস্থ না করে **আর্কিটেকচার বুঝে** লিনাক্স শিখতে চায়

## কীভাবে পড়বে?

1. **ক্রম অনুযায়ী পড়ো।** প্রতিটি অধ্যায় আগের অধ্যায়ের উপর দাঁড়িয়ে আছে।
2. **পড়ার সাথে সাথে টার্মিনালে টাইপ করো।** শুধু পড়ে লিনাক্স শেখা যায় না, হাতে-কলমে করতে হয়।
3. **প্রতিটি অধ্যায়ের শেষে "হাতে-কলমে অনুশীলন" আর "নিজেকে যাচাই করো" অংশ** অবশ্যই করবে।
4. **একটা Virtual Machine-এ অনুশীলন করো** (অধ্যায় ৩ দেখো), যাতে ভুল হলেও আসল কম্পিউটারের কোনো ক্ষতি না হয়।
5. শর্টকাটগুলো এক জায়গায় পেতে [পরিশিষ্ট ক](appendix-a-shortcuts-cheatsheet.md) প্রিন্ট করে পাশে রাখো।

## চিহ্নগুলোর মানে

| চিহ্ন | মানে |
|------|------|
| `$ command` | সাধারণ ইউজার হিসেবে চালানো কমান্ড (`$` টাইপ করবে না) |
| `# command` | root/sudo হিসেবে চালানো কমান্ড |
| > ⚠️ সতর্কতা | ভুল করলে ক্ষতি হতে পারে |
| > 💡 টিপস | কাজ সহজ করার কৌশল |
| > 📝 মনে রাখো | জরুরি কথা |
